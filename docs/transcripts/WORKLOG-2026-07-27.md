## Defects resolved

### CREATE and CREATE2

- Creator nonce ordering now matches the execution specification.
- EIP-150 message-gas reservation occurs before collision handling.
- Collision detection includes nonce, code, and EIP-7610 storage presence.
- Collision paths preserve their required gas consumption.

### SELFDESTRUCT

- A nonzero transfer to a new beneficiary charges the additional 25,000 gas.
- EIP-6780 deletion applies only to contracts created in the current
  transaction and remains deferred until transaction finalization.
- Pre-existing contracts retain their code and storage.
- Self-beneficiary behavior distinguishes pre-existing contracts from
  same-transaction creations.
- Deletion markers and state mutations are discarded when a child frame
  reverts.

### Reverted frame accounting

- EIP-2929 warm addresses and storage slots now use frame checkpoints.
  Additions made inside a reverted child frame are rolled back while
  parent-frame accesses remain warm.
- An insufficient-balance value CALL returns the unused child allocation but
  retains the correct net CALL charge, including stipend treatment.

### RPC simulation

- `eth_call`, `eth_estimateGas`, and `debug_traceCall` use explicit simulation
  authorization.
- Simulations retain intrinsic gas and normal EVM execution but bypass mined
  transaction nonce, fee, and sender-funding validation.
- Actual signed and impersonated transactions retain normal validation.
