A — Refractive Density

Execution as a heated medium. Gas consumption raises local "temperature" creating refractive-index gradients. The field shimmers where computation is expensive. State mutations produce thermal plumes. CALLs create boundary layers.

Luminance = instantaneous gas rate · Vertical displacement = accumulated state change · Turbulence = memory expansion pressure · Sharp boundary = CALL/RETURN context change · Continuous gradient = no discrete elements

B — Knife-Edge Schlieren

Literal Schlieren technique. A knife-edge cutoff renders the first derivative of execution density. Smooth execution is mid-grey. Sudden changes (gas spikes, state writes, halts) appear as bright/dark bands. The result looks like real Schlieren photography of supersonic flow.

Mid-grey = steady execution · Bright band = positive gas-rate-of-change (cost spike) · Dark band = negative change (return to cheap ops) · Vertical streak = state mutation · Horizontal shear = depth transition

C — Caustic Interference

Execution as light passing through a disturbed medium. Every opcode contributes a wave. Where waves concentrate, caustic bright lines form. Each transaction produces a unique interference fingerprint — visually compelling even with no errors.

Bright caustic lines = constructive interference from periodic patterns (loops, repeated ops) · Diffuse glow = high cumulative gas · Dark voids = untouched state regions · Fracture = phase discontinuity (rare red)
